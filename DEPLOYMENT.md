# 🎵 SPOTIFY CLONE - DEPLOYMENT GUIDE

## 🚀 DEPLOY ON VERCEL (EASY METHOD)

### Step 1: Go to Vercel Web
1. Open https://vercel.com
2. Login with your account
3. Click "Add New Project"

### Step 2: Import from GitHub
1. Select "Import Git Repository"
2. Paste: `https://github.com/shenn667/spotify-clone`
3. Click "Continue"

### Step 3: Configure
1. **Framework:** Next.js (auto-detected)
2. **Root Directory:** ./ (default)
3. **Build Command:** `npm run build` (auto)
4. **Output Directory:** `.next` (auto)
5. **Environment Variables:** None needed

### Step 4: Deploy
1. Click "Deploy"
2. Wait ~60 seconds
3. Your app will be live at: `https://spotify-clone-xxx.vercel.app`
